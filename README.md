# AI Daily Report Generator

面向解决方案架构师的访谈式 AI 日报生成器

## 项目概述

通过全双工实时语音对话（类似打电话）收集每日工作内容，自动生成结构化日报。

## 技术栈

- 前端: React 18 + Vite + TypeScript + Tailwind CSS
- 后端: Node.js + Express + Socket.io
- 数据库: PostgreSQL + Redis
- 实时通信: WebRTC
- API: 豆包 API (ASR/LLM/TTS)
